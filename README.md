# Galactic Upg Tree : Remade

An upgrade-tree incremental game. No build step and no dependencies.

## Publish on GitHub Pages

Upload `index.html`, `style.css`, `gate.js`, `core.js` and `app.js` to the root of a repository, then
**Settings -> Pages -> Deploy from a branch -> main / (root)**. The game will be at
`https://<your-username>.github.io/<repo-name>/`.
